# kuroko_isaac_config_generator

This package generates **USD / USDA assets for Isaac Lab** from the same robot description
that is used in Gazebo.

The conversion pipeline is intentionally aligned with Gazebo's internal behavior to avoid
URDF/SDF incompatibilities (fixed joint lumping, frame graphs, closed chains, etc.).

---

## Conversion Pipeline

```
xacro
  ↓
URDF
  ↓
SDF        (generated by Gazebo CLI)
  ↓
USD / USDA (generated by gz-usd)
```

Key design decisions:

- **URDF → SDF is done by Gazebo (`gz sdf -p`)**, not by custom code
- **SDF → USD is done by `gz-usd`**, not by Isaac Sim importers
- Isaac Lab only *loads* the resulting USD; it is not used for conversion

---

## Requirements

### System
- Ubuntu 22.04
- ROS 2
- Gazebo (gz-sim)
- USD (installed automatically with gz-usd)

---

## ROS 2 ↔ Gazebo Version Mapping (Important)

Gazebo (gz-sim) is released independently, but **each ROS 2 distribution targets a specific
Gazebo release by default**.

This mapping is important when selecting dependency versions for `gz-usd`.

| ROS 2 distribution | Default Gazebo | Notes |
|--------------------|---------------|-------|
| **Humble** (22.04) | **Gazebo Fortress** | LTS ↔ LTS pairing |
| **Iron** (22.04)   | **Gazebo Garden**   | Non‑LTS |
| **Jazzy** (24.04)  | **Gazebo Harmonic** | LTS ↔ LTS pairing |
| Rolling            | Latest (dev)        | May change frequently |

If you are using ROS 2 Humble (recommended), you should assume **Gazebo Fortress** APIs and
dependency versions.

## Installing gz-usd

`gz-usd` is the official Gazebo project for converting **SDF → USD**.

Repository:
https://github.com/gazebosim/gz-usd

---

### 1. Install dependencies (ROS 2 Humble / Gazebo Fortress)

For **ROS 2 Humble + Gazebo Fortress** on Ubuntu 22.04:

```bash
sudo apt update
sudo apt install -y \
  cmake \
  git \
  build-essential \
  libgz-common6-dev \
  libgz-math7-dev \
  libgz-msgs9-dev \
  libgz-transport12-dev \
  libgz-rendering8-dev \
  libgz-sim7-dev \
  libsdformat13-dev \
  libusd-dev
```

### Other ROS / Gazebo combinations

If you are using a different ROS 2 distribution:

- **Iron (Gazebo Garden)**  
  → dependency versions will be **one major version higher** than Fortress

- **Jazzy (Gazebo Harmonic)**  
  → expect newer `libgz-*` and `libsdformat` versions

Use the following command to inspect available versions:

```bash
apt search libgz-sim
apt search libsdformat
```

Then select versions matching your installed Gazebo release.

---

### 2. Clone gz-usd

```bash
mkdir -p ~/tools
cd ~/tools
git clone https://github.com/gazebosim/gz-usd.git
cd gz-usd
git checkout fortress
```

---

### 3. Build gz-usd

```bash
mkdir build
cd build
cmake ..
make -j$(nproc)
```

Install using `checkinstall` (recommended)

Instead of `sudo make install`, create a `.deb` package with `checkinstall`, then install it with `dpkg`.
This makes it easy to uninstall / upgrade cleanly later.

1) Install `checkinstall`:

```bash
sudo apt update
sudo apt install -y checkinstall
```

2) Run `checkinstall` from the build directory (non-interactive):

Specify package name, version, and `-y` to skip all prompts.

```bash
# from ~/tools/gz-usd/build
sudo checkinstall \
  --pkgname=gz-usd \
  --pkgversion=0.1.0 \
  --fstrans=no \
  --install=no \
  -D \
  -y
```

This will produce a `.deb` in the current directory.

3) Install the generated `.deb`:

```bash
sudo dpkg -i ./*.deb
```

If `dpkg` reports missing dependencies, fix them with:

```bash
sudo apt-get -f install
```

If you skip packaging / installation, make sure the built binaries are in your PATH:

```bash
export PATH=$HOME/tools/gz-usd/build/bin:$PATH
```

---

### 4. Verify installation

```bash
sdf2usd --help
```

You should see help output for the `gz usd` command.

## Using this package

### 1. Generate SDF from xacro

```bash
ros2 launch kuroko_isaac_config_generator xacro_to_sdf.launch.py
```

Output (default):

```
/tmp/kuroko_usd_out/kuroko.sdf
```

---

### 2. Convert SDF to USD / USDA

```bash
sdf2usd /tmp/kuroko_usd_out/kuroko.sdf /tmp/kuroko_usd_out/kuroko.usda
```

This USD can be loaded directly in Isaac Sim / Isaac Lab.

---

## Loading in Isaac Lab

In Isaac Lab, simply reference the generated USD:

```python
from omni.isaac.core.utils.stage import add_reference_to_stage

add_reference_to_stage(
    usd_path="/tmp/kuroko_usd_out/kuroko.usda",
    prim_path="/World/Kuroko",
)
```

No URDF or SDF importers are required.

---

## Why gz-usd?

- Correct handling of:
  - Fixed joints
  - Closed kinematic chains
  - `relative_to` frame graphs
- Matches Gazebo's interpretation of SDF
- Avoids Python / Conda / ABI issues
- Actively developed by the Gazebo team

---

## Notes

- This package intentionally avoids:
  - Isaac Sim URDF importer
  - Custom SDF parsers
  - Python-based SDF → USD conversion
- All heavy conversion work is delegated to Gazebo tooling.
